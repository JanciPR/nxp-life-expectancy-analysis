# Global Life Expectancy Analysis (1960–2023)

## Project overview

This project analyses how life expectancy at birth has changed across countries and World Bank income groups from 1960 to 2023. It combines statistical analysis, data visualisation, country-level forecasting and an interactive dashboard.

The analysis uses World Bank indicators to examine:
- Total, male and female life expectancy at birth
- Crude death rate
- Total fertility rate
- Country metadata, including region and income group

## Assignment coverage

### 1. Statistical analysis
- Compare the female-minus-male life expectancy gap across income groups between 1960 and 2023.
- Compare cross-country life expectancy variability using standard deviation and interquartile range (IQR).
- Identify countries with the strongest positive and negative correlations between fertility rate and life expectancy over time.
- Supplement level correlations with year-to-year change correlations to help interpret long-term trends.

### 2. Visualisations
- Life expectancy trends by income group (1960–2023).
- World choropleth of life expectancy at birth in 2023.
- Sankey diagram showing country transitions between five life-expectancy ranking buckets from 1960 to 2023.

### 3. Forecasting
The forecasting task uses information available up to and including 2010. The 2010 value is the last known observation and forecast origin; the evaluated forecast period is 2011–2023 (13 horizons, 217 countries).

Models (implemented in `src/model.py`, explained step by step in `notebooks/life_expectancy_forecasting.ipynb`):
- **Persistence** and **drift** (last value plus 10-year average annual gain) baselines.
- **ARIMA(1,1,0) with a linear trend**, fitted per country on data up to 2010.
- **Gradient boosting, direct multi-horizon**: predicts the change in life expectancy from the 2010 level, trained once with life-expectancy features only and once with fertility, death rate and the female–male gap added.

Evaluation:
- Training features are rebuilt for every historical origin year, and every training pair satisfies `origin + horizon ≤ 2010`.
- Expanding-window rolling-origin validation (origins 1995, 2000, 2005) checks stability inside the pre-2011 period.
- Final forecasts are scored against observed 2011–2023 values on one common set of country-years using MAE, median absolute error, RMSE, bias and skill versus persistence, with and without the COVID-19 years 2020–2022.

### 4. Interactive dashboard
The Streamlit dashboard monitors life expectancy at birth, crude death rate, fertility rate and the female–male life-expectancy gap for every country over 1960–2023.

- **Filters:** region, income group and country (the country list narrows to the chosen region and income group) plus a year range.
- **Grouping (bonus):** "View charts by" switches every trend chart between income group, region, individual countries and an overall average.
- **Life expectancy tab:** trend chart and a world map for any of the four indicators (map year = end of the selected range).
- **Death & fertility tab:** trend charts for both indicators.
- **Gender gap tab:** gap over time and a ranking of countries by the gap in their latest year.
- **Country profile tab:** a table with each country's region, income group and latest indicator values, and a detail view for a chosen country (life expectancy by sex, gap, death rate and fertility).
- **Data tab:** the filtered observations with the gap column, downloadable as CSV.

Group lines are unweighted means of the countries in each group; regional aggregates are excluded.

## Data source

Source: [World Bank Open Data](https://data.worldbank.org/)

The project uses the following World Bank indicators:

| Indicator | World Bank indicator code |
|---|---|
| Life expectancy at birth, total | `SP.DYN.LE00.IN` |
| Life expectancy at birth, male | `SP.DYN.LE00.MA.IN` |
| Life expectancy at birth, female | `SP.DYN.LE00.FE.IN` |
| Death rate, crude | `SP.DYN.CDRT.IN` |
| Fertility rate, total | `SP.DYN.TFRT.IN` |

The downloaded CSV files are included in `data/raw/`. The expected filenames are:

- `life_expectancy_total.csv`
- `life_expectancy_male.csv`
- `life_expectancy_female.csv`
- `death_rate.csv`
- `fertility_rate.csv`
- `life_expectancy_country_metadata.csv`

The raw data files are inputs to the project and are not generated by the analysis scripts. If you replace them, rebuild the processed dataset with `build_dataset(force=True)` (or delete `data/processed/world_bank_life_expectancy.csv`), because the processed file is cached.

## Environment setup

The project was developed with Python 3.10; `requirements.txt` pins the versions used for the reported results.

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd nxp_life_expectancy_analysis
```

### 2. Create and activate a virtual environment

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## Run the analysis

From the project root, run:

```bash
python run_analysis.py
```

The script builds the processed dataset, writes data-quality reports to `outputs/reports/`, runs the statistical analysis (tables in `outputs/tables/`), generates charts (`outputs/figures/`) and runs the forecasting pipeline (scores, per-country errors and `model_metrics.json` in `outputs/tables/`). Statistical and forecasting results use sovereign countries only; regional aggregates are excluded.

For the detailed, step-by-step analysis and methodology, open and run the notebooks in the `notebooks/` directory.

## Run the interactive dashboard

From the project root, with the virtual environment activated:

```bash
streamlit run app.py
```

Streamlit will provide a local URL in the terminal. Open that URL in your browser to use the dashboard.

## Methodological notes and limitations

- The analysis distinguishes country observations from regional and other aggregates where applicable.
- Income-group comparisons use the World Bank income-group classification available in the dataset. If current classifications are applied retrospectively, historical income-group comparisons should be interpreted with that limitation in mind.
- Country-level averages are unweighted unless explicitly stated otherwise.
- Paired endpoint comparisons (gender gap, variability) include only countries with valid observations in both 1960 and 2023, so the same countries are compared at both endpoints.
- Correlation does not imply causation. Correlations across annual levels can be influenced by shared long-term trends.
- The forecasting cutoff is 2010. Data after 2010 is reserved for forecast evaluation and is not used to construct the 2010-origin features or train the final forecasting models.
- Forecast accuracy is affected by unexpected shocks (COVID-19, conflict, epidemics, the 2010 Haiti earthquake at the forecast origin), missing observations and country-specific events. Point forecasts do not capture prediction uncertainty.

## Reproducibility

For reproducibility:
1. Use the same source CSV files in `data/raw/`.
2. Install dependencies from `requirements.txt`.
3. Run the notebooks from top to bottom, or execute the project script from the repository root.
4. Generated tables, figures and reports are written to `outputs/`; re-run `python run_analysis.py` to regenerate them.
